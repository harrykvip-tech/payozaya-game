# ပျော်စရာဂိမ်း (Glass UI)

ဂိမ်း ၂၂ ခု၊ ဖိုင်တစ်ခုတည်း (`index.html`)၊ build မလို။

## GitHub Pages နဲ့ တင်နည်း
1. GitHub မှာ repository အသစ်ဆောက်ပါ
2. ဒီဖိုင် ၄ ခုလုံး (`index.html`, `manifest.webmanifest`, `icon.svg`, `README.md`) upload လုပ်ပါ
3. Settings → Pages → Branch: `main` / root → Save
4. ခဏကြာရင် `https://<username>.github.io/<repo>/` မှာ ဖွင့်လို့ရပါမယ်

## ဖုန်းမှာ app လို သွင်းနည်း
- Android Chrome: ⋮ → Install app / Add to Home screen
- iPhone Safari: Share → Add to Home Screen
